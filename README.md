# FishFeed Backend

REST API for FishFeed — an aquarium fish feeding management app with gamification. Handles users, aquariums, fish, feeding logs, scheduled notifications, image uploads, in-app purchases, and multi-device offline-first sync.

## Stack

FastAPI · PostgreSQL · Redis · SQLAlchemy 2.x (async) · Alembic · APScheduler · Firebase Cloud Messaging · APNs · RevenueCat · Hetzner S3 · Sentry · Docker · GitHub Actions

## Status

Source published for transparency. Closed to external contributions.
